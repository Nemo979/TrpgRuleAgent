# Stage 3 Complex 启动条件复核

Stage 3 不因题目较长或领域较多而自动引入 Planner。当前复核分三层：

1. 结构探针：当前最多 4 个子问题能否表达任务数、领域、依赖边和条件分支；
2. 本地检索门：PF1E 金来源是否可达，以及正式 Stage 2 串行路径能否读到全部来源组；
3. 真实答案门：同一批合成题由 MiMo 回答时，事实、来源、条件推理和预算是否通过。

## 合成数据

- `complex-task-cases.jsonl`：10 个纯合成 Complex 结构案例，其中 4 个独立目标、6 个依赖/条件案例；
- `complex-task-retrieval-cases.jsonl`：8 个本地规则证据可达性探针；
- `complex-task-answer-cases.jsonl`：6 个 Planner 候选的答案事实与来源组金集。

这些文件不包含真实用户数据。结构与检索评测不调用外部模型；真实答案评测必须另行获得明确授权。
