# Rule Data Policy

TrpgRuleAgent 的源代码与规则内容分离。

- 原始 CHM、解包 HTML、结构化父文档和向量索引全部保存在 Git 忽略的 `data/` 目录。
- 仓库只提交少量明确标记为 `metadata.demo=true` 的合成演示文本。
- 用户必须自行确认其导入、使用和分发规则资料的权限。
- 导入报告记录文档数量、异常文件和编码，不复制规则正文。
- 公开部署前，应为每个 Rule Pack 明确来源、许可范围和允许展示的引用长度。

PF1E 规则资料不随仓库分发。每位使用者需要自行提供其有权使用的 CHM；文件名、正文、哈希和生成索引均不会进入版本控制。
