# Rule Data Policy

TrpgRuleAgent 的源代码与规则内容分离。

- 原始 PDF/CHM、CHM 解包 HTML、结构化父文档、导入报告和向量索引默认全部保存在 Git 忽略的 `data/` 目录。
- 仓库只提交少量明确标记为 `metadata.demo=true` 的合成演示文本。
- Rule Pack 可以提交不含规则正文的完整性元数据，例如规范化文件名和
  SHA-256；这些值用于管理员核对本地资料和保持重复导入的一致性，不代表仓库分发该资料。
- 用户必须自行确认其导入、使用和分发规则资料的权限。
- 导入报告记录文档数量、异常文件、编码或页级警告，不复制规则正文。
- 公开部署前，应为每个 Rule Pack 明确来源、许可范围和允许展示的引用长度。

PF1E、《夕妖晚谣》和其他商业规则资料均不随仓库分发。每位使用者需要自行提供
其有权使用的 PDF 或 CHM；原文件、规则正文、解析产物和生成索引不会进入版本控制。
