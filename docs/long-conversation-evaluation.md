# 长会话与 revision 评测

## 范围

V2.3 Stage 0 使用 12/24/48 轮夹具和一条真实缺陷重放验证两层契约：

- 确定性评测：状态保留、显式覆盖、助手内容不污染状态、Context 裁剪、指代增强和 revision mismatch；
- 真实答案评测：把合成历史作为预置上下文，只执行每个 case 的目标规则问题，验证事实、来源和工具预算。

评测不改变线上 Prompt、检索排序或模型调用路径。

## Case Schema

`rulepacks/pathfinder-1e/evals/long-conversation-cases.jsonl` 每行包含：

- `history.turnCount`：12、24 或 48；
- `fillerUser` / `fillerAssistant`：不改变状态的合成轮次；
- `events`：指定轮次的用户明确状态和助手干扰文本；
- `expectedState`：以点路径表示的期望字段；
- `overwritePaths`：必须以最新用户声明覆盖的字段；
- `forbiddenState`：不得从助手文本或旧值进入最终 State 的字段；
- Context 分配、revision mismatch、Query Rewrite probe 的预期；
- `artifactProbe`：用户明确要求检查上一版答案时，必须选中相关助手草案，且该草案不得进入 State
  或充当规则证据；
- `turns`：沿用答案评测的目标问题、金来源和必需事实。

合成历史会在内存中展开。确定性报告和 turn metrics 不写入历史正文、规则正文或答案。
答案评测的本地诊断报告沿用通用评测格式，会包含目标问题、模型答案和来源元数据；该文件位于
被 Git 忽略的生成目录，仅用于本地排错，不得提交。提交的基线结论只保留聚合数字和布尔结果。

## 命令

确定性契约：

```bash
npm run eval:long-context:pf
```

真实 MiMo 答案基线会发送合成历史、目标问题和已读 PF1E 证据，必须先取得授权：

```bash
TRPG_TURN_METRICS_PATH=data/pathfinder-1e/generated/long-conversation-turn-metrics.jsonl \
  npm run eval:answer:pf:long
```

## 2026-08-26 Codex 式连续任务回归

新增 `catfolk-medium-point-buy-review-5`，重放“20buy、5 级、猫族、通灵者、虚空之声”以及
错误属性建议被用户要求复核的完整前置历史。服务器现在区分三类上下文：用户明确状态、已注册
规则证据、待审查的上一版助手草案。草案只在明确引用时选择一条，最多保留 12,000 字符；它不
进入 State，不进入检索证据，也不能被最终答案引用为来源。

State 新增职业、变体和购点预算；裸 `5级` 不再生成伪职业 `级`。属性/购点后续检索会按问题范围
恢复种族、职业、变体和预算。若已注册证据同时包含完整购点表与对应种族调整，服务器对六项购点
前属性执行确定性核算，并把预算差额、种族后期望值和上一版差异作为不可篡改的算术结果交给生成器。

纯本地确定性评测为 4/4：State 保留、覆盖、污染隔离、Query Rewrite 和 artifact reference 均为
100%。经单独明确外发授权，真实 MiMo 首轮暴露了新的严格缺陷：模型虽然修正了猫族感知与魅力，
却把总消耗只有 14 点的方案称为正确的 20 点方案；原自动断言又因属性值中出现 `14` 而假通过。

整改后，证据充分时最终购点核算改由服务器直接渲染，不再让模型改写确定性结果；自动断言同时收紧
为必须出现合计 14、剩余 6、感知 12、魅力 14。相同授权 payload 的复验答案严格正确，两份金来源
均命中、工具调用 4 次且在预算内。原报告因 `-2感知` 与 Markdown 表格表示差异记为未通过，修正
格式兼容后的纯本地重评分为 1/1。
